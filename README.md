# Anuflix — Movies & TV

A premium movie and TV show discovery app powered by the [TMDB API](https://www.themoviedb.org/).

## Features

- 🎬 Hero banner with featured content
- 🔟 Top 10 trending today
- 🎞️ Horizontal carousels (Trending, Now Playing, Top Rated, Popular TV)
- 🔍 Search movies & TV shows
- 📋 Watchlist (saved to localStorage)
- 📱 Responsive — desktop sidebar + mobile bottom tabs
- ⚡ Skeleton loading states

## Setup

1. Get a free API key from [TMDB](https://www.themoviedb.org/settings/api)
2. Open the app and paste your key in the welcome modal

## Tech Stack

- Vanilla HTML / CSS / JavaScript
- TMDB API v3
- No frameworks, no build tools
